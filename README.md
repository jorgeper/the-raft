# the-raft

A monorepo for assorted personal projects. Each folder is its own project and keeps its own README.

| Folder | What it is | Moved from |
|---|---|---|
| `three-whimsical-world/` | three.js whimsical world experiments | `jorgeper/3d-tests` |
| `disk-scout/` | Disk usage explorer | `jorgeper/disk-scout` |
| `packrat/` | FTP backup tool for game servers | `jorgeper/packrat` |
| `mail-archive/` | Local Mac app for searching a Gmail Takeout | `jorgeper/mail-archive` |
| `old-stuff/` | Archive of old experiments and side projects | `jorgeper/graveyard` |
| `archive/` | Former sandbox monorepo of personal experiments | `jorgeper/sandbox` |

Each project's full commit history was carried over with its files moved into its folder. Old tags are prefixed with the folder name (e.g. `packrat/v0.2.0`).
